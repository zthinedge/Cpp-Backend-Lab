# 从零学习 Linux perf

这不是命令手册，而是一组循序渐进的实验。你不需要提前知道 `perf`、CPU
计数器或汇编是什么。

## 学习规则

1. 按顺序学习，不要一开始就看火焰图。
2. 每输入一条命令，先阅读命令下方的“逐段解释”。
3. 输出中的数字不必与文档相同；不同电脑的结果本来就不同。
4. 第一遍只需要理解大意，不需要背命令。

## 这个 lab 里有哪些文件？

```text
perf/
├── README-CN.md          你正在看的课程入口
├── lessons/              每一课的讲义
├── examples/
│   └── perf_lab.cpp      故意制造性能现象的 C++ 程序
├── scripts/              学会手动操作后再使用的辅助脚本
└── Makefile              告诉 make 如何编译示例
```

这些文件不是 `perf` 软件本身。`perf` 已经安装在 Linux 系统中，这个目录只是
用于学习它的教材和实验程序。

## 学完的标准

学完后不要求记住所有选项。只要能用自己的话回答下面的问题即可：

- `perf stat` 和 `perf record` 有什么区别？
- 什么是“热点函数”？
- 为什么性能分析应该使用接近真实情况的输入？
- 如何找到一个慢程序最值得优先检查的函数？
